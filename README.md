# ZOG-ZERO-OVERHEAD-GENIUS-
ZOG (Zero-Overhead Genius) is an open-source AI study companion that turns messy PDFs and Google Classroom files into interactive quizzes. Using 100% open-weight local models like Llama 3 via Ollama, ZOG creates isolated, context-aware learning spaces for every class. It is a privacy-first, free model harness built for college students.
